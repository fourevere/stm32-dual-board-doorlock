# STM32 2-Board 스마트 도어락

정광근의 Cortex-M4 임베디드 프로젝트. 개발 기간 **2026.07.23-07.27**, 문서·공개 사본 정리 **2026.09.12**.

![전체 배선](docs/assets/board-overview.jpg)

키패드·RC522 인증과 서보·LED·부저 구동을 BOARD_A에, LCD 상태 표시와 IR 원격 입력을 BOARD_B에 배치했습니다. UART 명령 프레임과 RX 인터럽트로 두 보드를 연결하며, C로 주변장치 레지스터를 직접 제어합니다.

## 구현 범위

- 3자리 비밀번호 확인·취소, 관리자 카드의 비밀번호 변경·재확인
- SPI2 기반 RC522 UID 읽기, TIM3 PWM 서보와 TIM1 부저, LED 알림
- I2C1 LCD 상태 출력, TIM2·EXTI IR 간격 판정
- STX / CMD / LEN / DATA / XOR / ETX 프레임과 BOARD_A / BOARD_B 빌드 분기

역할은 **도어락 애플리케이션·주변장치 통합**으로 정리합니다. 개별 커밋 근거가 없어 모든 기반 코드의 독자 작성이나 기여율을 주장하지 않습니다. CMSIS·ST 헤더와 교육 기반 시작 코드가 포함됩니다.

## 빌드

Windows의 Arm GNU Toolchain 15.2.Rel1 (gcc 15.2.1), GNU Make 3.81로 확인했습니다. 기본 Makefile은 해당 툴체인의 설치 경로를 사용하므로 환경에 맞게 TOOL_DIR을 지정합니다. 각 보드용으로 **새로 복사한 별도 저장소의 루트**에서 다음 중 하나를 실행합니다.

```text
make -C firmware all BOARD_DEF=-DBOARD_A
make -C firmware all BOARD_DEF=-DBOARD_B
```

같은 폴더에서 BOARD_DEF만 바꾸면 기존 .o가 재사용될 수 있으므로, 다른 보드는 새 복사본에서 빌드하세요. 현재 작업에서는 원본·공개 사본 각각 두 보드를 새로 빌드했고 모두 종료 코드 0입니다. 공개 사본은 경고 0 / 오류 0, BIN은 A 28,208 bytes / B 27,612 bytes입니다. 하드웨어 재실행은 수행하지 않았습니다.

초기 비밀번호는 공개용 예제 `000`이며 카드 UID도 예제값입니다. 실제 테스트 전 본인의 카드 값으로 로컬에서 설정해야 합니다. 이 예제값 교체는 9/12 공개 준비 변경입니다.

## 현재 한계

- 클록 설정은 96 MHz인데 UART 링크의 84 MHz, LCD의 42 MHz 상수가 혼재합니다. 실제 baud·I2C 주기는 계측하지 않았습니다.
- UART LEN 상한·명령별 길이 검사, ACK·재전송·수신 타임아웃이 없습니다.
- 비밀번호는 RAM에 저장되고 변경 내용이 UART·디버그 로그로 전송됩니다. UID 비교와 3자리 입력, IR 원격 명령에는 실제 운영 수준의 인증 설계가 없습니다.
- 3회 실패 후 카운터를 초기화하며 시간 잠금은 없습니다. 입력·구동 일부가 busy-wait이고 이벤트 큐가 없습니다.

이는 교육용 기능 통합 프로토타입입니다. 확인하지 않은 성공률·반복 시험 횟수·응답 시간은 표기하지 않습니다.

## 개발 이력

개발 기간은 2026.07.23-07.27입니다. GitHub에 표시되는 작성자 날짜와 커밋 날짜는 개발 종료일인 7/27의 대표 시각으로 맞췄습니다. 원래의 일별 Git 이력은 없으며, 실제 복원·문서화·공개 등록은 2026.09.12에 진행했습니다.

개발일지의 날짜별 일정은 최종 소스에 근거한 사후 재구성입니다. 최종 ZIP에는 문서·사진·영상만 있어 소스는 별도 보존 스냅샷에서 복원했습니다. 구체적인 출처와 변경 범위는 [복원 이력](docs/provenance.md)에 정리했습니다.
